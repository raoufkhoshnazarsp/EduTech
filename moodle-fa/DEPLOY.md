# راهنمای استقرار گام‌به‌گام

این فایل را از بالا تا پایین دنبال کنید. هر قدم را که تمام کردید، تیک بزنید و بروید سراغ بعدی. جایی گیر کردید، بخش «اگر گیر کردی» انتهای فایل را ببینید.

**زمان کل: حدود ۳۰ دقیقه** (که ۱۰ دقیقه‌اش انتظار است، نه کار کردن).

---

## قدم ۰ — قبل از شروع، این سه چیز را آماده کن

| چیز | چه‌کار کنم |
|---|---|
| **IP سرور** | در پنل لیارا، صفحهٔ سرور، مقدار IPv4 را کپی کنید |
| **رمز root** | هنگام ساخت سرور دریافت کردید (ایمیل یا پنل لیارا) |
| **زیردامنهٔ رایگان** | در [duckdns.org](https://www.duckdns.org) با گوگل وارد شوید ← یک نام بنویسید (مثل `myacademy`) ← در فیلد `current ip` همان IP سرور را بگذارید ← `update ip` |

> **این قدم آخر را جدی بگیرید.** بدون DuckDNS، سایت بالا می‌آید ولی بدون قفل HTTPS می‌ماند و مرورگر به دانش‌آموزان هشدار «ناامن» نشان می‌دهد.

---

## قدم ۱ — وصل شدن به سرور

### اگر ویندوز دارید

دکمهٔ Start را بزنید، `PowerShell` را باز کنید و بزنید:

```powershell
ssh root@IP-سرور
```

مثلاً `ssh root@185.10.20.30`

### اگر مک یا لینوکس دارید

`Terminal` را باز کنید و همان دستور:

```bash
ssh root@IP-سرور
```

### اولین بار این پیام می‌آید

```
The authenticity of host '185.10.20.30' can't be established.
Are you sure you want to continue connecting (yes/no)?
```

`yes` بنویسید و Enter بزنید. بعد رمز root را بزنید.

> **نکته:** موقع تایپ رمز، هیچ ستاره یا نقطه‌ای نمایش داده نمی‌شود. این طبیعی است. رمز را بزنید و Enter.

**علامت موفقیت:** علامت خط فرمان به چیزی مثل `root@server:~#` تغییر می‌کند.

## قدم ۲ — فرستادن فایل‌های پروژه به سرور

فایل `moodle-fa-deploy.tar.gz` را از پنل دانلود کنید و روی کامپیوتر خودتان بگذارید (مثلاً در `Downloads`).

**یک پنجرهٔ ترمینال جدید باز کنید** (پنجرهٔ قبلی که به سرور وصل است را نبندید) و در آن این را بزنید:

```bash
scp ~/Downloads/moodle-fa-deploy.tar.gz root@IP-سرور:/root/
```

> در ویندوز مسیر را این‌طور بنویسید: `scp $env:USERPROFILE\Downloads\moodle-fa-deploy.tar.gz root@IP-سرور:/root/`

رمز را بزنید. چند ثانیه صبر کنید.

**برگردید به پنجرهٔ متصل به سرور** و باز کنید:

```bash
cd /root
tar xzf moodle-fa-deploy.tar.gz
cd moodle-fa
ls
```

**باید این‌ها را ببینید:** `docker-compose.yml`، `.env.example`، `README.md`، `docs`، `scripts`

## قدم ۴ — تنظیم پروژه

```bash
cp .env.example .env
nano .env
```

حالا فایل تنظیمات باز می‌شود. فقط این چهار خط را عوض کنید:

```bash
DUCKDNS_SUBDOMAIN="myacademy"        # ← نامی که در DuckDNS ساختی
MOODLE_PASSWORD="RamzGhavi123!"      # ← یک رمز قوی برای خودت
DB_PASS="RamzDigar456!"              # ← یک رمز دیگر، فقط حروف و رقم
MOODLE_SITENAME="آموزشگاه من"        # ← نام واقعی
```

بقیه را دست نزنید (ایمیل را بعداً تنظیم می‌کنیم).

**ذخیره در nano:**
1. `Ctrl + O` (حرف او، نه صفر)
2. `Enter`
3. `Ctrl + X`

**بررسی اینکه درست ذخیره شد:**

```bash
grep DUCKDNS_SUBDOMAIN .env
grep MOODLE_PASSWORD .env
```

باید مقادیر خودتان را ببینید، نه `myacademy` نمونه.

## قدم ۵ — اجرای نصب

```bash
sudo bash scripts/install.sh
```

حالا **دست به کیبورد نزنید**. اسکریپت این مراحل را طی می‌کند:

```
==> نصب داکر (اگر نصب نباشد)
==> دانلود ایمیج‌ها و راه‌اندازی (چند دقیقه طول می‌کشد)
==> انتظار برای آماده شدن دیتابیس و Moodle
==> نصب بسته زبان فارسی
==> تنظیم فارسی به‌عنوان زبان پیش‌فرض
==> فعال‌کردن ردیابی پیشرفت، نشان‌ها و کارنامه
==> تنظیم پیش‌فرض آزمون‌ها (نمره‌دار + تمرینی)
==> نصب افزونه گواهی پایان دوره (Custom Certificate)
==> پاک‌سازی کش
==> نصب nginx و گواهی SSL برای myacademy.duckdns.org
==> بررسی DNS برای myacademy.duckdns.org
==> فعال‌کردن پشتیبان‌گیری روزانه
```

حدود ۵ تا ۱۰ دقیقه. صبر کنید. اگر جایی گیر کرد، `Ctrl + C` نزنید — اجازه بدهید پیام خطا را نشان دهد.

**در پایان باید این را ببینید:**

```
==> تمام شد

آدرس سایت:  https://myacademy.duckdns.org
نام کاربری:  admin
رمز عبور:    (همان که در .env گذاشتید)
```

## قدم ۶ — اولین ورود

مرورگر را باز کنید و آدرس سایت را بزنید. **باید قفل سبز (HTTPS) ببینید.**

وارد شوید با:
- نام کاربری: `admin`
- رمز: همان که در قدم ۴ گذاشتید

> اگر صفحهٔ سفید یا خطای ۵۰۲ دیدید، ۲ دقیقه صبر کنید و رفرش کنید. اولین بار Moodle زمان می‌برد.

## قدم ۷ — تنظیمات اولیه (۱۰ دقیقه)

این چهار کار را انجام دهید. همه از منوی **«مدیریت سایت»** در سمت چپ-بالا.

### ۷.۱ — مطمئن شو فارسی فعال است

**مدیریت سایت ← زبان‌ها ← بسته‌های زبان**

باید «فارسی (fa)» را در لیست ببینید و بالای صفحه نوشته باشد «زبان پیش‌فرض: فارسی».

اگر نبود، در همان صفحه «فارسی» را انتخاب و «نصب بستهٔ زبان انتخاب‌شده» را بزنید.

### ۷.۲ — قالب را روی Boost بگذار

**مدیریت سایت ← ظاهر ← تم‌ها ← Boost ← «استفاده به‌عنوان تم پیش‌فرض»**

Boost سبک‌ترین و سازگارترین قالب با راست‌به‌چپ است.

### ۷.۳ — ثبت‌نام خودکار را خاموش کن

**مدیریت سایت ← افزونه‌ها ← احراز هویت ← مدیریت احراز هویت**

مطمئن شوید **«ثبت‌نام مبتنی بر ایمیل»** خاموش است. فقط شما دانش‌آموز می‌سازید.

### ۷.۴ — یک دستهٔ درس بساز

**مدیریت سایت ← دوره‌ها ← افزودن دستهٔ دوره**

نام: مثلاً «پایه دهم». این ظرفی است که درس‌ها داخلش می‌روند.

---

## قدم ۸ — ساختن اولین درس و کلاس

**مدیریت سایت ← دوره‌ها ← افزودن دورهٔ جدید**

| فیلد | چه بگذارید |
|---|---|
| نام کامل | «ریاضی دهم — کلاس الف» |
| نام کوتاه | `MATH10-A` ← **این را یادداشت کنید**، برای ورود دانش‌آموزان لازم است |
| دستهٔ دوره | «پایه دهم» |
| قالب | Topics |

بعد از ذخیره، در صفحهٔ درس، تب **«شرکت‌کنندگان» ← «روش‌های ثبت‌نام»** ← **«ثبت‌نام دستی»** را فعال کنید. بدون این، هیچ دانش‌آموزی نمی‌تواند وارد درس شود.

**گروه‌بندی (اختیاری ولی مفید):** در همان صفحهٔ درس ← «شرکت‌کنندگان» ← «گروه‌ها» ← «گروه‌های خودکار ایجاد شود» ← تعداد گروه و نحوهٔ توزیع.

---

## قدم ۹ — وارد کردن ۵۰۰ دانش‌آموز از اکسل

### ۹.۱ — اکسل را آماده کن

فایل اکسل شما باید این ستون‌ها را داشته باشد (نام فارسی هم قبول است):

| ستون | مثال |
|---|---|
| نام | علی |
| نام خانوادگی | رضایی |
| ایمیل | ali@example.com |
| کد ملی | 0012345678 |
| نام کاربری | ali.rezaei (اختیاری) |
| درس | MATH10-A (اختیاری) |
| گروه | A (اختیاری) |

اگر ستون «نام کاربری» نباشد، خودکار از کد ملی ساخته می‌شود.

مفیدترین حالت: ستون `درس` را همان «نام کوتاه» درس بگذارید (مثل `MATH10-A`). آن‌وقت دانش‌آموزان مستقیم داخل کلاس ثبت‌نام می‌شوند.

### ۹.۲ — تبدیل به CSV

**روی کامپیوتر خودتان** (نه سرور) — پایتون لازم است:

```bash
python3 excel-to-moodle-csv.py students.xlsx -o students.csv
```

> بدون پایتون؟ فایل اکسل را در گوگل‌شیت باز کنید ← `File` ← `Download` ← `Comma-separated values (.csv)` و ستون‌ها را به همان نام‌های بالا تغییر دهید.

خروجی باید چیزی شبیه این باشد:

```
✓ 500 دانش‌آموز در فایل «students.csv» نوشته شد.
```

### ۹.۳ — آپلود در Moodle

1. **مدیریت سایت ← کاربران ← حساب‌ها ← بارگذاری دسته‌ای کاربران**
2. فایل `students.csv` را انتخاب کنید
3. نوع: **CSV** ← «بارگذاری»
4. صفحهٔ پیش‌نمایش می‌آید ← ستون‌ها را چک کنید ← **«بارگذاری کاربران»**

**باید ببینید:** «۵۰۰ کاربر ساخته شد».

> رمز پیش‌فرض همه `ChangeMe123!` است. برای امنیت بیشتر، بعداً از دانش‌آموزان بخواهید عوض کنند.

## قدم ۱۰ — ساخت آزمون نمره‌دار و تمرینی

### آزمون نمره‌دار

1. داخل درس ← **«افزودن فعالیت یا منبع»** ← **«آزمون»**
2. نام: «میان‌ترم ریاضی»
3. در تب **«زمان‌بندی»**: باز شدن و بسته شدن را تعیین کنید
4. ذخیره ← روی «بانک سؤال» کلیک کنید ← **«افزودن دستهٔ جدید»** ← سؤالات را بسازید
5. برگردید به آزمون ← **«افزودن سؤال از بانک سؤال»**
6. تب **«نمره»**: «نمرهٔ بیشترین» = `20`
7. تب **«مرور گزینه‌ها»**: جلوی «نمره» برای دانش‌آموز «بله» بگذارید

### آزمون تمرینی

همان مراحل، با دو تفاوت:

- تب **«نمره»**: «نمرهٔ بیشترین» = `0`
- تب **«مرور گزینه‌ها»**: «بازخورد فوری» را روی «بله» بگذارید

نمره‌اش در کارنامه ثبت نمی‌شود و دانش‌آموز بی‌نهایت بار می‌تواند تمرین کند.

**نکتهٔ صرفه‌جویی در وقت:** یک بانک سؤال برای هر درس بسازید و سؤالات را دوباره استفاده کنید. برای آزمون اصلی، در «افزودن سؤال» گزینهٔ «سؤال تصادفی از دسته» را بزنید تا هر دانش‌آموز سؤال متفاوت بگیرد.

## قدم ۱۱ — ساخت تکلیف

داخل درس ← **«افزودن فعالیت یا منبع»** ← **«تکلیف»**

| فیلد | چه بگذارید |
|---|---|
| نام | «تمرین فصل ۳» |
| توضیحات | صورت سؤال را بنویسید |
| نوع تکلیف | «بارگذاری فایل» |
| انواع فایل مجاز | PDF و Word و عکس |
| حداکثر حجم | ۲۰ مگابایت |
| تاریخ تحویل | مهلت را بگذارید |
| روش نمره‌دهی | «نمره» از ۲۰ |

بعد از تحویل، از **«نمایش/نمره‌دهی همهٔ تحویل‌ها»** می‌توانید تک‌تک نمره و بازخورد بدهید.

---

## قدم ۱۲ — فعال کردن گواهی پایان دوره

افزونه در نصب خودکار نصب شده. برای استفاده:

1. داخل درس ← **«افزودن فعالیت یا منبع»** ← **«گواهی (Custom Certificate)»**
2. نام: «گواهی پایان دورهٔ ریاضی دهم»
3. روی «طراحی گواهی» کلیک کنید ← «افزودن عنصر» ← متن، تصویر، کد یکتا
4. متن را فارسی بنویسید: «{studentname} دورهٔ ... را با موفقیت گذراند»
5. تب **«شرایط»**: «فعالیت‌ها تکمیل شده» ← درس را انتخاب کنید
6. ذخیره

دانش‌آموز بعد از تکمیل شرایط می‌تواند PDF گواهی را دانلود کند.

---

## قدم ۱۳ — پشتیبان‌گیری خودکار (انجام شده، فقط بررسی کن)

بعد از نصب، هر شب ساعت ۳ صبح خودکار پشتیبان گرفته می‌شود.

**بررسی اینکه کار می‌کند:**

```bash
sudo /usr/local/bin/moodle-backup
ls -lh /var/backups/moodle/
```

**باید دو فایل ببینید:** `db-...sql.gz` و `moodledata-...tar.gz`

**مهم:** این پشتیبان‌ها روی همان سرور هستند. اگر سرور از بین برود، پشتیبان هم از بین می‌رود. **هفته‌ای یک‌بار** فایل‌ها را با `scp` روی کامپیوتر خودتان کپی کنید:

```bash
scp root@IP-سرور:/var/backups/moodle/*.gz ~/Downloads/
```

## قدم ۱۴ — پیگیری روزانهٔ دانش‌آموزان

این‌ها را هر روز یا هر هفته استفاده کنید:

| چه‌کاری | کجا |
|---|---|
| نمرهٔ همهٔ آزمون‌ها و تکالیف | گزارش‌ها ← نمرات |
| چه کسی کدام بخش را دیده | گزارش‌ها ← تکمیل فعالیت |
| آخرین دسترسی هر دانش‌آموز | گزارش‌ها ← مشارکت در درس |
| **دانش‌آموزان غیرفعال** | درس ← شرکت‌کنندگان ← فیلتر «دسترسی نداشته در ۱۴ روز» |
| چه کسی تکلیف نداده | تکلیف ← «نمایش/نمره‌دهی» ← فیلتر «ارسال نکرده» |
| نمرات را در اکسل بگیر | درس ← نمرات ← «خروجی» ← Excel |

**پیشنهاد:** هفته‌ای یک‌بار «بدون دسترسی در ۱۴ روز» را ببینید و به آن دانش‌آموزان پیام بدهید. این مهم‌ترین ابزار پیگیری شماست.

## کارهای بعدی (اختیاری)

### ایمیل را وصل کن

بدون ایمیل، دانش‌آموزان نمی‌توانند رمزشان را بازیابی کنند.

1. اگر Gmail دارید: در حساب گوگل، **App Password** بسازید (امنیت ← تأیید دومرحله‌ای ← رمزهای برنامه)
2. `nano .env` ← این‌ها را پر کنید:

```bash
SMTP_HOST="smtp.gmail.com"
SMTP_PORT="587"
SMTP_USER="your@gmail.com"
SMTP_PASSWORD="رمز-برنامه-نه-رمز-گوگل"
SMTP_PROTOCOL="tls"
MOODLE_MAIL_NOREPLY_ADDRESS="your@gmail.com"
```

3. ذخیره کنید و بزنید:

```bash
docker compose up -d
```

4. در Moodle: **مدیریت سایت ← سرور ← ایمیل ← تست کردن تنظیمات ایمیل**

### محدودیت حجم آپلود

در `.env` این سه خط را هر وقت خواستید بالاتر ببرید (پیش‌فرض ۵۰ مگ است):

```bash
client_max_body_size: 100M
post_max_size: 100M
upload_max_filesize: 100M
```

بعد `docker compose up -d`. **به‌یاد داشته باشید** `client_max_body_size` در nginx هم هست: `/etc/nginx/sites-available/moodle` را هم عوض کنید.

### به‌روزرسانی

```bash
cd /root/moodle-fa
sudo /usr/local/bin/moodle-backup
sed -i 's|alpine-moodle:5.3|alpine-moodle:5.4|' docker-compose.yml
docker compose pull && docker compose up -d
docker compose logs -f moodle
```

منتظر پیام `Moodle code sync` بمانید، بعد `Ctrl + C`.

## اگر گیر کردی

| چه می‌بینی | یعنی چه | چه‌کار کن |
|---|---|---|
| `ssh: command not found` | ویندوز قدیمی | PowerShell را با دسترسی Administrator باز کن و بزن: `Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0` |
| `Permission denied (publickey,password)` | رمز اشتباه | رمز را از پنل لیارا چک کن؛ یا در پنل «ریست رمز» بزن |
| `scp: command not found` | روی ویندوز | از `scp $env:USERPROFILE\Downloads\...` استفاده کن |
| preflight: `✗ رم` | پلن کوچک خریدی | به لیارا برو و پلن را به «اورانوس» ارتقا بده |
| preflight: `✗ پورت 80 اشغال` | وب‌سرور دیگری روی سرور است | `systemctl stop apache2 nginx` بعد دوباره نصب کن |
| نصب: `Moodle در ۵ دقیقه بالا نیامد` | دیتابیس کند بالا آمده | `docker compose logs moodle` و `docker compose logs db` را ببین |
| `هشدار: دامنه ... اشاره نمی‌کند` | DuckDNS هنوز IP قدیمی را دارد | در duckdns.org IP را درست کن، یا `DUCKDNS_TOKEN` را در `.env` بگذار تا خودکار به‌روز شود |
| سایت باز می‌شود ولی قفل ندارد | SSL صادر نشد | `certbot --nginx -d myacademy.duckdns.org` دستی اجرا کن |
| متن فارسی جدا جدا | فونت یا قالب | تم Boost را انتخاب کن + `docker compose exec moodle php /var/www/html/admin/cli/purge_caches.php` |
| ورود نمی‌شود | رمز یا `wwwroot` | `docker compose exec moodle php /var/www/html/admin/cli/cfg.php --name=wwwroot` باید آدرس درست را نشان دهد |
| آپلود تکلیف خطای حجم | `client_max_body_size` کم | هر دو جا (`.env` و nginx) را بالا ببر |
| بعد از ری‌استارت همه چیز رفته | volume پاک شده | `docker compose ps` و `docker volume ls` را ببین |

**دستور طلایی وقتی چیزی کار نمی‌کند:**

```bash
cd /root/moodle-fa
docker compose ps
docker compose logs --tail=50 moodle
```
