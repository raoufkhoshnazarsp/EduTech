# سامانه آموزش آنلاین فارسی — Moodle روی VPS

این پوشه یک نصب آماده از **Moodle** است: رایگان، متن‌باز (GPL)، فارسی و راست‌به‌چپ، با آزمون نمره‌دار و تمرینی، تکالیف، انجمن، پیگیری پیشرفت، گواهی پایان دوره و مدیریت کلاس. کلاس زنده در آن برگزار نمی‌شود و لازم هم نیست.

---

## چرا Moodle؟

از میان گزینه‌های متن‌باز، Moodle تنها گزینه‌ای است که **هر شش نیاز شما** را بدون افزونهٔ پولی و بدون کدنویسی پوشش می‌دهد:

| نیاز شما | در Moodle |
|---|---|
| آزمون نمره‌دار و تمرینی | ماژول Quiz با ۱۵+ نوع سؤال، نمره‌دهی خودکار، بانک سؤال، زمان‌بندی، محدودیت تلاش، و حالت «تمرین بدون نمره» |
| بارگذاری تکلیف | ماژول Assignment با آپلود فایل، مهلت، نمره و بازخورد نوشتاری/صوتی |
| پرسش و پاسخ دانش‌آموزان | Forum (پرسش‌وپاسخ)، Chat، پیام خصوصی |
| پیگیری پیشرفت | Gradebook، Completion tracking، گزارش‌های Activity/Course participation، فهرست «بدون فعالیت در ۱۴ روز» |
| انجمن / کامیونیتی | انجمن در سطح درس و سطح سایت |
| مدیریت کلاس و گروه | Course categories، Groups & Groupings، Cohorts، نقش Teacher/Non-editing teacher |
| گواهی پایان دوره | افزونهٔ Custom Certificate (در نصب خودکار نصب می‌شود) |

**فارسی بودن:** بستهٔ زبان فارسی را دانلود و بررسی کردم — پوشش ترجمهٔ هسته عملاً کامل است:

| فایل | ترجمه‌شده |
|---|---|
| `moodle.php` (عمومی) | ۱۹۴۱ از ۱۹۴۲ |
| `admin.php` (مدیریت) | ۱۱۹۴ از ۱۲۰۰ |
| `quiz.php` (آزمون) | ۸۱۴ از ۸۱۴ |
| `assign.php` (تکلیف) | ۳۴۸ از ۳۴۹ |
| `forum.php` (انجمن) | ۴۶۶ از ۴۶۶ |

راست‌به‌چپ هم خودکار با انتخاب فارسی فعال می‌شود.

### گزینه‌های دیگر و چرا انتخاب نشدند

| سامانه | ستاره گیت‌هاب | مجوز | مشکل برای شما |
|---|---|---|---|
| **Moodle** | ۷٬۶۱۳ | GPL-3.0 | — (انتخاب شد) |
| **LearnHouse** | ۲٬۴۷۴ | AGPL-3.0 | رابط مدرن و نصب آسان، اما ترجمهٔ فارسی و RTL ندارد |

| **Open edX** | — | AGPL-3.0 | برای ۵۰۰ نفر بیش از حد سنگین؛ حداقل ۱۶ گیگ رم |
| **Canvas LMS** | — | AGPL-3.0 | نصب Ruby بسیار پیچیده؛ برای مبتدی مناسب نیست |

## کدام سرور لیارا را بگیرم؟

قیمت‌های زیر از صفحهٔ قیمت لیارا (تومان، ماهانه) است:

| پلن | رم | vCPU | دیسک | ماهانه | مناسب؟ |
|---|---|---|---|---|---|
| مشتری | ۲ GB | ۱ | ۲۰ GB | ۱٬۴۷۵٬۰۰۰ | ❌ کم است |
| زحل | ۴ GB | ۲ | ۴۰ GB | ۲٬۶۵۰٬۰۰۰ | ⚠️ برای شروع، ولی برای ۵۰۰ نفر تنگ |
| **اورانوس** | **۸ GB** | **۴** | **۸۰ GB** | **۴٬۶۰۰٬۰۰۰** | ✅ **انتخاب درست** |
| نپتون | ۱۶ GB | ۸ | ۱۶۰ GB | ۸٬۰۰۰٬۰۰۰ | برای ۵۰۰ نفر زیاد است |

**پیشنهاد من: پلن «اورانوس» — ۸ گیگ رم، ۴ هسته، ۸۰ گیگ دیسک.**

دلیل: ۵۰۰ دانش‌آموز یعنی حدود ۳۰ نفر همزمان. Moodle با PHP و PostgreSQL در همین حد راحت جواب می‌دهد. «زحل» با ۴ گیگ هم بالا می‌آید ولی موقع آزمون همزمان و آپلود تکالیف، رم کم می‌آورد و کند می‌شود.

**نکته‌های هزینه که در جدول نیست:**
- **IPv4 ماهانه ۲۰۰٬۰۰۰ تومان** جدا حساب می‌شود — بدون آن سرور از اینترنت دیده نمی‌شود.
- **ترافیک دانلود هر گیگابایت ۲٬۵۰۰ تومان**؛ آپلود رایگان. برای ۵۰۰ دانش‌آموز که فایل و ویدیو دانلود می‌کنند، این را جدی بگیرید. اگر ویدیو زیاد می‌گذارید، هزینهٔ ترافیک از هزینهٔ سرور بیشتر می‌شود.
- **پرداخت ساعتی** دارد؛ می‌توانید یک ماه تست کنید و اگر جواب نداد پلن را عوض کنید.

**در لیارا موقع ساخت سرور، گزینهٔ «Docker» را انتخاب کنید** تا داکر از قبل نصب باشد و اسکریپت سریع‌تر پیش برود. سیستم‌عامل: Ubuntu 24.04.

> ⚠️ پلن‌های PaaS لیارا (زمین/مریخ/...) برای Moodle مناسب نیستند: Moodle به دیسک ماندگار برای `moodledata` و اجرای cron نیاز دارد که روی VPS ساده‌تر و ارزان‌تر است.

## دامنه ندارید؟ دو راه

### راه ۱ (پیشنهادی و رایگان): DuckDNS

اسکریپت نصب خودش این را انجام می‌دهد. فقط قبلش:

1. به [duckdns.org](https://www.duckdns.org) بروید و با گوگل/گیت‌هاب وارد شوید
2. یک نام انتخاب کنید، مثلاً `myacademy`
3. در فیلد `current ip` مقدار IP سرور لیارا را بگذارید
4. موقع اجرای نصب، همان نام را وارد کنید

نتیجه: آدرس `https://myacademy.duckdns.org` با **گواهی SSL معتبر و رایگان**. DuckDNS در لیست دامنه‌های عمومی است، پس Let's Encrypt بدون مشکل گواهی می‌دهد.

### راه ۲: خرید دامنه

یک دامنهٔ `.ir` یا `.com` ارزان بخرید و در `.env` مقدار `SITE_URL` را روی آن بگذارید. حرفه‌ای‌تر است و برای بلندمدت بهتر.

> بدون هیچ‌کدام، سایت فقط با `http://IP` بالا می‌آید — کار می‌کند ولی مرورگرها «ناامن» نشان می‌دهند و رمز دانش‌آموزان روی شبکهٔ باز رد و بدل می‌شود. برای سامانهٔ آموزشی این قابل قبول نیست.

## نصب در ۵ قدم

### قدم ۰ — پیش‌نیازها

- سرور لیارا پلن **اورانوس** با Ubuntu 24.04
- دسترسی SSH به سرور

### قدم ۱ — انتقال فایل‌ها

از روی کامپیوتر خودتان:

```bash
scp -r moodle-fa root@IP-سرور:/root/
```

### قدم ۲ — پر کردن تنظیمات

```bash
ssh root@IP-سرور
cd /root/moodle-fa
cp .env.example .env
nano .env
```

| کلید | چه بگذارید |
|---|---|
| `SITE_URL` | خالی بگذارید اگر دامنه ندارید (اسکریپت خودش می‌سازد) |
| `MOODLE_SITENAME` | نام آموزشگاه، مثلاً «آموزشگاه دانش» |
| `MOODLE_PASSWORD` | یک رمز قوی برای حساب مدیر |
| `DB_PASS` | یک رمز دیگر، فقط حروف و رقم |
| `SMTP_*` | اطلاعات ایمیل خودتان (برای بازیابی رمز) |

ذخیره: `Ctrl+O` بعد `Enter` بعد `Ctrl+X`

### قدم ۳ — اجرای نصب

```bash
sudo bash scripts/install.sh
```

اسکریپت این کارها را انجام می‌دهد:

1. نصب داکر و docker compose
2. بالا آوردن Moodle و PostgreSQL
3. دانلود و نصب بستهٔ زبان فارسی + تنظیم فارسی به‌عنوان پیش‌فرض
4. فعال‌کردن ردیابی پیشرفت، نشان‌ها و کارنامه
5. نصب افزونهٔ **گواهی پایان دوره**
6. ساخت زیردامنهٔ رایگان DuckDNS + نصب nginx + گواهی SSL
7. فعال‌کردن پشتیبان‌گیری روزانه

حدود ۵ تا ۱۰ دقیقه.

### قدم ۴ — ورود

آدرسی که اسکریپت در پایان چاپ می‌کند را باز کنید و با `MOODLE_USERNAME` و `MOODLE_PASSWORD` وارد شوید.

### قدم ۵ — تنظیم اولیه (۱۰ دقیقه)

1. **مدیریت سایت ← زبان‌ها ← بسته‌های زبان**: مطمئن شوید «فارسی» نصب و پیش‌فرض است.
2. **مدیریت سایت ← ظاهر ← تم‌ها**: تم `Boost` را انتخاب کنید (سبک و سازگار با RTL).
3. **مدیریت سایت ← افزونه‌ها ← ثبت‌نام**: «ثبت‌نام خودکار» خاموش است — فقط شما دانش‌آموز می‌سازید.
4. یک «دستهٔ درس» بسازید (مثلاً «پایه دهم») و داخلش درس‌ها را ایجاد کنید.

## وارد کردن دانش‌آموزان از اکسل

Moodle فایل `.xlsx` را مستقیم نمی‌خورد؛ باید CSV شود. اسکریپت مبدل را گذاشتم:

```bash
python3 scripts/excel-to-moodle-csv.py students.xlsx -o students.csv
```

**سرستون‌های اکسل شما می‌تواند فارسی باشد.** این نام‌ها شناخته می‌شوند:

| ستون اکسل | فیلد Moodle |
|---|---|
| نام کاربری | `username` |
| نام | `firstname` |
| نام خانوادگی | `lastname` |
| ایمیل | `email` |
| کد ملی | `idnumber` |
| درس | `course1` |
| گروه | `group1` |

اگر ستون «نام کاربری» نداشتید، از کد ملی ساخته می‌شود. اگر ایمیل خالی بود، ایمیل موقت ساخته می‌شود. نام‌های تکراری خودکار شماره می‌خورند.

سپس در Moodle: **مدیریت سایت ← کاربران ← حساب‌ها ← بارگذاری دسته‌ای کاربران** ← فایل CSV را انتخاب کنید ← پیش‌نمایش ← تأیید.

> رمز پیش‌فرض همه `ChangeMe123!` است. بعد از اولین ورود، از دانش‌آموزان بخواهید عوض کنند، یا با `--password` رمز دیگری بدهید.

## آزمون نمره‌دار و تمرینی

هر دو در Moodle هست، فقط تنظیمش فرق می‌کند:

**آزمون نمره‌دار:** داخل درس ← افزودن فعالیت ← آزمون ← در تب «نمره» ← «نمرهٔ بیشترین» را بگذارید ← در «مرور گزینه‌ها» نمایش نمره را برای دانش‌آموز روشن کنید.

**آزمون تمرینی:** همان آزمون، ولی در تب «نمره» ← «نمرهٔ بیشترین» را `0` بگذارید و در «رفتار سؤال» ← «بازخورد فوری» را انتخاب کنید. نمره در کارنامه ثبت نمی‌شود و دانش‌آموز بی‌نهایت بار می‌تواند تلاش کند.

**بانک سؤال مشترک:** سؤالات را یک‌بار در «بانک سؤال» درس بسازید و در چند آزمون استفاده کنید — برای آزمون‌های تمرینی و اصلی از یک منبع.

## گواهی پایان دوره

افزونه در نصب خودکار نصب می‌شود. برای صدور:

1. داخل درس ← افزودن فعالیت ← **گواهی (Custom Certificate)**
2. قالب را انتخاب کنید (قالب فارسی را می‌توانید در «مدیریت قالب‌ها» بسازید)
3. در تب «شرایط» ← «فعالیت‌ها تکمیل شده» را انتخاب کنید
4. دانش‌آموز بعد از تکمیل شرایط، گواهی PDF را دانلود می‌کند

## کارهای روزمره

### پیگیری وضعیت دانش‌آموزان
- **گزارش‌ها ← نمرات**: نمرهٔ همهٔ آزمون‌ها و تکالیف در یک جدول
- **گزارش‌ها ← تکمیل فعالیت**: چه کسی کدام بخش را دیده
- **گزارش‌ها ← مشارکت در درس**: آخرین دسترسی هر دانش‌آموز
- **درس ← شرکت‌کنندگان ← فیلتر «بدون فعالیت در ۱۴ روز»**: دانش‌آموزان غیرفعال

### پشتیبان‌گیری
خودکار هر شب ساعت ۳ در `/var/backups/moodle`. دستی:

```bash
sudo /usr/local/bin/moodle-backup
```

## دستورهای پرکاربرد

```bash
cd /root/moodle-fa

docker compose ps                 # وضعیت سرویس‌ها
docker compose logs -f moodle     # دیدن لاگ
docker compose restart moodle     # ری‌استارت
docker compose down               # خاموش کردن
docker compose up -d              # روشن کردن
```

### به‌روزرسانی Moodle

```bash
cd /root/moodle-fa
sudo /usr/local/bin/moodle-backup     # اول پشتیبان
sed -i 's|alpine-moodle:5.3|alpine-moodle:5.4|' docker-compose.yml
docker compose pull && docker compose up -d
docker compose logs -f moodle         # منتظر پیام «Moodle code sync» بمانید
```

> همیشه روی تگ `X.Y` بمانید (مثل `5.3`)، نه `latest`. تگ `latest` ممکن است یک‌شبه نسخهٔ اصلی را عوض کند و ارتقای دیتابیس برگشت‌پذیر نیست.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| صفحه سفید یا خطای ۵۰۲ | `docker compose logs moodle`؛ معمولاً دیتابیس هنوز بالا نیامده — ۲ دقیقه صبر کنید |
| متن فارسی جدا جدا نشان داده می‌شود | مدیریت سایت ← ظاهر ← تم‌ها ← Boost؛ بعد کش را پاک کنید |
| آپلود تکلیف خطای حجم می‌دهد | در `.env` مقدار `client_max_body_size` را بالا ببرید و `docker compose up -d` بزنید |
| ایمیل بازیابی رمز نمی‌آید | تنظیمات `SMTP_*` را بررسی کنید؛ برای Gmail باید App Password بسازید |
| گواهی SSL گرفته نشد | `certbot --nginx -d دامنه‌تان` را دستی اجرا کنید |
| DuckDNS آدرس را باز نمی‌کند | در duckdns.org مطمئن شوید IP با IP سرور یکی است؛ تا ۵ دقیقه انتشار DNS صبر کنید |

## نکته‌های مهم

- **فایل `.env` را در گیت نگذارید** — رمزها داخلش است.
- **۵۰۰ دانش‌آموز یعنی حدود ۳۰ نفر همزمان**، نه ۵۰۰.
- **کلاس زنده لازم نیست** — Moodle برای آموزش ناهمزمان ساخته شده.
- **توسعهٔ شخصی:** هر افزونه‌ای از [moodle.org/plugins](https://moodle.org/plugins) را نصب کنید؛ برای کد اختصاصی، پوشهٔ `local/` را در volume نگه دارید.
