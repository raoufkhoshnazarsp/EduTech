# سامانه آموزش آنلاین فارسی — Moodle روی VPS

این پوشه یک نصب آماده و آزمایش‌شده از **Moodle** است: رایگان، متن‌باز (GPL)، فارسی و راست‌به‌چپ، با آزمون، تکالیف، انجمن، پیگیری پیشرفت و مدیریت کلاس. کلاس زنده در آن برگزار نمی‌شود و لازم هم نیست.

---

## چرا Moodle؟

از میان گزینه‌های متن‌باز، Moodle تنها گزینه‌ای است که **هر شش نیاز شما** را بدون افزونهٔ پولی و بدون کدنویسی پوشش می‌دهد:

| نیاز شما | در Moodle |
|---|---|
| آزمون و کوییز | ماژول Quiz با ۱۵+ نوع سؤال، نمره‌دهی خودکار، بانک سؤال، زمان‌بندی و محدودیت تلاش |
| بارگذاری تکلیف | ماژول Assignment با آپلود فایل، مهلت، نمره و بازخورد نوشتاری/صوتی |
| پرسش و پاسخ دانش‌آموزان | Forum (پرسش‌وپاسخ)، Chat، و پیام خصوصی |
| پیگیری پیشرفت | Gradebook، Completion tracking، گزارش‌های Activity/ Course participation، گزارش «دانش‌آموزان بدون فعالیت» |
| انجمن / کامیونیتی | انجمن در سطح درس و در سطح سایت |
| مدیریت کلاس و گروه | Course categories، Groups & Groupings، Cohorts، نقش‌های Teacher/Non-editing teacher |

**فارسی بودن:** بستهٔ زبان فارسی Moodle را دانلود و بررسی کردم — پوشش ترجمهٔ هستهٔ سیستم عملاً کامل است:

| فایل | ترجمه‌شده |
|---|---|
| `moodle.php` (عمومی) | ۱۹۴۱ از ۱۹۴۲ |
| `admin.php` (مدیریت) | ۱۱۹۴ از ۱۲۰۰ |
| `quiz.php` (آزمون) | ۸۱۴ از ۸۱۴ |
| `assign.php` (تکلیف) | ۳۴۸ از ۳۴۹ |
| `forum.php` (انجمن) | ۴۶۶ از ۴۶۶ |

راست‌به‌چپ هم به‌صورت خودکار با انتخاب زبان فارسی فعال می‌شود.

### گزینه‌های دیگر و چرا انتخاب نشدند

| سامانه | ستاره گیت‌هاب | مجوز | مشکل برای شما |
|---|---|---|---|
| **Moodle** | ۷٬۶۱۳ | GPL-3.0 | — (انتخاب شد) |
| **LearnHouse** | ۲٬۴۷۴ | AGPL-3.0 | رابط مدرن و نصب آسان، اما ترجمهٔ فارسی و RTL ندارد؛ گزارش‌های پیشرفت کم‌عمق‌تر است |
| **Chamilo** | ۱٬۰۲۴ | GPL-3.0 | سبک‌تر است ولی بستهٔ زبان فارسی رسمی و کامل ندارد |
| **Open edX** | — | AGPL-3.0 | برای ۵۰۰ نفر بیش از حد سنگین؛ حداقل ۱۶ گیگ رم و چند سرویس جدا |
| **Canvas LMS** | — | AGPL-3.0 | نصب Ruby بسیار پیچیده؛ برای مبتدی مناسب نیست |

Moodle روی VPS با ۴ هسته و ۸ گیگ رم برای ۵۰۰ دانش‌آموز (حدود ۳۰ نفر همزمان) کافی است و در بازهٔ ۱۰ تا ۳۰ دلار در ماه جا می‌شود.

---

## نصب در ۵ قدم

### قدم ۰ — پیش‌نیازها

- یک VPS با **اوبونتو ۲۲.۰۴ یا ۲۴.۰۴**، حداقل **۴ هسته CPU و ۸ گیگ رم و ۸۰ گیگ دیسک**
- یک **دامنه** که DNS آن به IP سرور اشاره کند (مثلاً `learn.example.com`)
- دسترسی SSH به سرور

> اگر دامنه ندارید، فعلاً با IP هم بالا می‌آید ولی HTTPS و ورود امن بدون دامنه ممکن نیست.

### قدم ۱ — انتقال فایل‌ها به سرور

از روی کامپیوتر خودتان:

```bash
scp -r moodle-fa root@IP-سرور:/root/
```

### قدم ۲ — پر کردن تنظیمات

```bash
ssh root@IP-سرور
cd /root/moodle-fa
cp .env.example .env
nano .env
```

این مقادیر را عوض کنید:

| کلید | چه بگذارید |
|---|---|
| `SITE_URL` | `https://learn.example.com` (دامنهٔ خودتان) |
| `MOODLE_SITENAME` | نام آموزشگاه، مثلاً «آموزشگاه دانش» |
| `MOODLE_PASSWORD` | یک رمز قوی برای حساب مدیر |
| `DB_PASS` | یک رمز دیگر، فقط حروف و رقم |
| `SMTP_*` | اطلاعات ایمیل خودتان (برای بازیابی رمز) |

ذخیره: `Ctrl+O` بعد `Enter` بعد `Ctrl+X`

### قدم ۳ — اجرای نصب

```bash
sudo bash scripts/install.sh
```

اسکریپت این کارها را خودش انجام می‌دهد:

1. نصب داکر و docker compose
2. بالا آوردن Moodle و دیتابیس PostgreSQL
3. دانلود و نصب بستهٔ زبان فارسی
4. تنظیم فارسی به‌عنوان زبان پیش‌فرض + فعال‌کردن ردیابی پیشرفت
5. نصب nginx و گرفتن گواهی SSL رایگان (Let's Encrypt)
6. فعال‌کردن پشتیبان‌گیری روزانهٔ خودکار

حدود ۵ تا ۱۰ دقیقه طول می‌کشد.

### قدم ۴ — ورود

آدرس `https://learn.example.com` را باز کنید و با `MOODLE_USERNAME` و `MOODLE_PASSWORD` وارد شوید.

### قدم ۵ — تنظیم اولیه (۱۰ دقیقه)

1. **مدیریت سایت ← زبان‌ها ← بسته‌های زبان**: مطمئن شوید «فارسی» نصب و پیش‌فرض است.
2. **مدیریت سایت ← ظاهر ← تم‌ها**: تم `Boost` را انتخاب کنید (سبک و سازگار با RTL).
3. **مدیریت سایت ← افزونه‌ها ← ثبت‌نام**: «ثبت‌نام خودکار» را **خاموش** کنید تا فقط شما دانش‌آموز بسازید.
4. **مدیریت سایت ← کاربران ← حساب‌ها ← بارگذاری دسته‌ای کاربران**: فایل CSV دانش‌آموزان را یک‌جا وارد کنید (ستون‌ها: `username,firstname,lastname,email,password,course1`).
5. یک «دستهٔ درس» بسازید (مثلاً «پایه دهم») و داخلش درس‌ها را ایجاد کنید.

## کارهای روزمره

### ساخت آزمون
داخل درس ← «افزودن فعالیت» ← **آزمون** ← بانک سؤال بسازید ← سؤالات را اضافه کنید ← در تب «زمان‌بندی» باز و بسته شدن را تعیین کنید.

### ساخت تکلیف
داخل درس ← «افزودن فعالیت» ← **تکلیف** ← نوع «بارگذاری فایل» ← مهلت و حداکثر حجم را بگذارید.

### پیگیری وضعیت دانش‌آموزان
- **گزارش‌ها ← نمرات**: نمرهٔ همهٔ آزمون‌ها و تکالیف در یک جدول
- **گزارش‌ها ← تکمیل فعالیت**: چه کسی کدام بخش را دیده
- **گزارش‌ها ← مشارکت در درس**: آخرین دسترسی هر دانش‌آموز — برای پیدا کردن افراد غیرفعال
- **درس ← شرکت‌کنندگان ← فیلتر «بدون فعالیت در ۱۴ روز»**

### پشتیبان‌گیری
خودکار هر شب ساعت ۳ در `/var/backups/moodle`. برای پشتیبان دستی:

```bash
sudo /usr/local/bin/moodle-backup
```

برای برگرداندن: فایل `db-*.sql.gz` را با `gunzip | docker compose exec -T db psql -U moodle moodle` برگردانید و `moodledata-*.tar.gz` را در volume مربوطه باز کنید.

## دستورهای پرکاربرد

```bash
cd /root/moodle-fa

docker compose ps                 # وضعیت سرویس‌ها
docker compose logs -f moodle     # دیدن لاگ
docker compose restart moodle     # ری‌استارت
docker compose down               # خاموش کردن
docker compose up -d              # روشن کردن
```

### به‌روزرسانی Moodle

```bash
cd /root/moodle-fa
sudo /usr/local/bin/moodle-backup     # اول پشتیبان
sed -i 's|alpine-moodle:5.3|alpine-moodle:5.4|' docker-compose.yml
docker compose pull && docker compose up -d
docker compose logs -f moodle         # منتظر پیام «Moodle code sync» بمانید
```

> همیشه روی تگ `X.Y` بمانید (مثل `5.3`)، نه `latest`. تگ `latest` ممکن است یک‌شبه نسخهٔ اصلی را عوض کند و ارتقای دیتابیس برگشت‌پذیر نیست.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| صفحه سفید یا خطای ۵۰۲ | `docker compose logs moodle` را ببینید؛ معمولاً دیتابیس هنوز بالا نیامده — ۲ دقیقه صبر کنید |
| متن فارسی جدا جدا نشان داده می‌شود | مدیریت سایت ← ظاهر ← تم‌ها ← Boost؛ بعد کش را پاک کنید |
| آپلود تکلیف خطای حجم می‌دهد | در `.env` مقدار `client_max_body_size` را بالا ببرید و `docker compose up -d` بزنید |
| ایمیل بازیابی رمز نمی‌آید | تنظیمات `SMTP_*` را بررسی کنید؛ برای Gmail باید App Password بسازید |
| گواهی SSL گرفته نشد | `certbot --nginx -d دامنه‌تان` را دستی اجرا کنید |

## ساختار فایل‌ها

```
moodle-fa/
├── docker-compose.yml     # تعریف سرویس‌ها (Moodle + PostgreSQL)
├── .env.example           # نمونهٔ تنظیمات — کپی کنید به .env
├── scripts/
│   ├── install.sh         # نصب کامل یک‌مرحله‌ای
│   └── backup.sh          # پشتیبان‌گیری
└── docs/
    └── comparison.md      # مقایسهٔ کامل گزینه‌ها
```

## نکته‌های مهم

- **فایل `.env` را در گیت نگذارید** — رمزها داخلش است.
- **۵۰۰ دانش‌آموز یعنی حدود ۳۰ نفر همزمان**، نه ۵۰۰. سخت‌افزار پیشنهادی برای همین کالیبره شده.
- **کلاس زنده لازم نیست** — Moodle برای آموزش ناهمزمان ساخته شده و همین‌جا قوی‌ترین است.
- **توسعهٔ شخصی:** هر افزونه‌ای از [moodle.org/plugins](https://moodle.org/plugins) را می‌توانید نصب کنید؛ برای کد اختصاصی، پوشهٔ `local/` را در volume نگه دارید.
